# Get-R1DataSourceGroup

## SYNOPSIS
Returns the data source groups.

## SYNTAX

```
Get-R1DataSourceGroup [<CommonParameters>]
```

## DESCRIPTION
Returns the groups data sources may be assigned to.

## EXAMPLES

### Example 1
```powershell
Get-R1DataSourceGroup
```

Returns every data source group.
