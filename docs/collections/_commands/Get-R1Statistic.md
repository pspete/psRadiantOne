# Get-R1Statistic

## SYNOPSIS
Returns entry statistics.

## SYNTAX

```
Get-R1Statistic [<CommonParameters>]
```

## DESCRIPTION
Returns the entry statistics gathered by the deployment.

## EXAMPLES

### Example 1
```powershell
Get-R1Statistic
```

Returns the entry statistics.
