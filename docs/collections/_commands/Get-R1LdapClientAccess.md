# Get-R1LdapClientAccess

## SYNOPSIS
Returns the LDAP client access settings.

## SYNTAX

```
Get-R1LdapClientAccess [<CommonParameters>]
```

## DESCRIPTION
Returns the LDAP controls offered to clients: paged results, virtual list view, persistent search and
proxy authorization.

## EXAMPLES

### Example 1
```powershell
Get-R1LdapClientAccess
```

Returns the LDAP client access settings.
