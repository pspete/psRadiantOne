# Get-R1DirectorySchemaFile

## SYNOPSIS
Returns the directory schema files.

## SYNTAX

```
Get-R1DirectorySchemaFile [<CommonParameters>]
```

## DESCRIPTION
Returns the name of every schema file held on the server.

## EXAMPLES

### Example 1
```powershell
Get-R1DirectorySchemaFile
```

Returns the name of every schema file.
