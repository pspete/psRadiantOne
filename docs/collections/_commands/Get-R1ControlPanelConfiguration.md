# Get-R1ControlPanelConfiguration

## SYNOPSIS
Returns the control panel configuration.

## SYNTAX

```
Get-R1ControlPanelConfiguration [<CommonParameters>]
```

## DESCRIPTION
Returns the control panel configuration, covering the colour theme, session timeout, concurrent user
limit, banner and message of the day.

## EXAMPLES

### Example 1
```powershell
Get-R1ControlPanelConfiguration
```

Returns the control panel configuration.
