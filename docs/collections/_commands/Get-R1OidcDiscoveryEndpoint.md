# Get-R1OidcDiscoveryEndpoint

## SYNOPSIS
Returns the known OIDC discovery endpoints.

## SYNTAX

```
Get-R1OidcDiscoveryEndpoint [<CommonParameters>]
```

## DESCRIPTION
Returns the OIDC discovery endpoints the deployment knows about, for use as the discoveryUrl of
the other OIDC commands.

## EXAMPLES

### Example 1
```powershell
Get-R1OidcDiscoveryEndpoint
```

Returns the known discovery endpoints.
