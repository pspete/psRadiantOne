# Get-R1DataSourcePlugin

## SYNOPSIS
Returns the data source plugins.

## SYNTAX

```
Get-R1DataSourcePlugin [<CommonParameters>]
```

## DESCRIPTION
Returns every plugin installed to provide custom data source types.

## EXAMPLES

### Example 1
```powershell
Get-R1DataSourcePlugin
```

Returns every installed plugin.
