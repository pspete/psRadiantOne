# Get-R1GlobalLimit

## SYNOPSIS
Returns the global limits.

## SYNTAX

```
Get-R1GlobalLimit [<CommonParameters>]
```

## DESCRIPTION
Returns the global server limits, covering connection counts, search size and time limits, timeouts and
thread counts.

## EXAMPLES

### Example 1
```powershell
Get-R1GlobalLimit
```

Returns the global limits.
