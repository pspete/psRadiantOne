# Get-R1PublishedSchema

## SYNOPSIS
Returns the published schemas.

## SYNTAX

```
Get-R1PublishedSchema [<CommonParameters>]
```

## DESCRIPTION
Returns the name of every schema currently published to the server.

## EXAMPLES

### Example 1
```powershell
Get-R1PublishedSchema
```

Returns every published schema.
