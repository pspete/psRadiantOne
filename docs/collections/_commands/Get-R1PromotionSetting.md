# Get-R1PromotionSetting

## SYNOPSIS
Returns the configuration promotion settings.

## SYNTAX

```
Get-R1PromotionSetting [<CommonParameters>]
```

## DESCRIPTION
Returns the settings governing configuration promotion.

## EXAMPLES

### Example 1
```powershell
Get-R1PromotionSetting
```

Returns the promotion settings.
