# Get-R1WhatsNew

## SYNOPSIS
Returns the what's new content.

## SYNTAX

```
Get-R1WhatsNew [<CommonParameters>]
```

## DESCRIPTION
Returns the what's new content shown in the control panel for the installed version.

## EXAMPLES

### Example 1
```powershell
Get-R1WhatsNew
```

Returns the what's new content.
