# Get-R1SpecialGroup

## SYNOPSIS
Returns the special groups settings.

## SYNTAX

```
Get-R1SpecialGroup [<CommonParameters>]
```

## DESCRIPTION
Returns the DNs of the groups configured as the special users group and the administrators group.

## EXAMPLES

### Example 1
```powershell
Get-R1SpecialGroup
```

Returns the special groups settings.
