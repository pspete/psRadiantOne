# Get-R1DashboardLink

## SYNOPSIS
Returns the dashboard links.

## SYNTAX

```
Get-R1DashboardLink [<CommonParameters>]
```

## DESCRIPTION
Returns the links shown on the control panel dashboard.

## EXAMPLES

### Example 1
```powershell
Get-R1DashboardLink
```

Returns the dashboard links.
