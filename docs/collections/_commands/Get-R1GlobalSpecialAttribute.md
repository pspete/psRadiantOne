# Get-R1GlobalSpecialAttribute

## SYNOPSIS
Returns the global special attribute settings.

## SYNTAX

```
Get-R1GlobalSpecialAttribute [<CommonParameters>]
```

## DESCRIPTION
Returns the special attribute settings which apply across the whole namespace, being the attribute
used to record group membership.

## EXAMPLES

### Example 1
```powershell
Get-R1GlobalSpecialAttribute
```

Returns the global special attribute settings.
