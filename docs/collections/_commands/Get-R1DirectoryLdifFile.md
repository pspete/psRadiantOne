# Get-R1DirectoryLdifFile

## SYNOPSIS
Returns the LDIF files on the server.

## SYNTAX

```
Get-R1DirectoryLdifFile [<CommonParameters>]
```

## DESCRIPTION
Returns the name of every LDIF file held on the server.

## EXAMPLES

### Example 1
```powershell
Get-R1DirectoryLdifFile
```

Returns every LDIF file.
